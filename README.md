# Web Application Security Learning Portfolio

This repository documents my hands-on learning journey in Web Application Security, with a focus on vulnerability identification, HTTP analysis, access control testing, authentication security, and professional vulnerability reporting.

## Objectives

- Build a strong foundation in web application security.
- Develop practical skills using Burp Suite and Linux.
- Understand how common web vulnerabilities occur.
- Practice identifying and validating vulnerabilities in authorized environments.
- Improve technical documentation and vulnerability reporting skills.
- Progress toward professional web application penetration testing.

## Tools and Technologies

- Burp Suite Community Edition
- Kali Linux
- Firefox Developer Tools
- PortSwigger Web Security Academy
- HTTP/HTTPS

## Scope and Ethics

All security testing documented in this repository is performed in intentionally vulnerable training environments or within explicitly authorized testing scopes.

Sensitive information, authentication tokens, private API keys, and third-party user data are excluded from public documentation.

## Disclaimer

This repository represents ongoing practical training and skill development. Training lab solutions are not presented as real-world vulnerability discoveries.
